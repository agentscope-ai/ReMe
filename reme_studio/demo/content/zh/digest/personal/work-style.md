# 工作习惯

团队习惯先把原始记录写入文件，再总结为长期知识。内部资料默认保留在受控工作区，发送外部模型前需要确认实际部署与提供商设置。

林澄倾向在会议后当天记录结论；周宁在发布前检查恢复能力；何悦用现场反馈修正未验证的假设。

这些习惯来自 [[resources/kickoff.md|启动约定]] 和 [[resources/offline-feedback.md|现场限制]]。它们可以帮助 Agent 理解上下文，但用户应能检查、修改或删除过时的偏好。
