# Requirements draft · 2026-09-14

Aurora helps a five-person product team recover project context, meeting conclusions, and operating experience. The pilot supports Markdown; users own the files and can read them with an ordinary editor.

## Initial proposal

The first proposal used a central cloud database: upload meetings, generate knowledge centrally, and require an online connection for every query. This is a discussion draft, not an approved architecture. Field conditions still need validation.

## Acceptance goals

- Every significant conclusion leads back to an original record.
- A topic can be found across resources, daily notes, and durable knowledge.
- Users can export their memory without a proprietary database format.
- Later decisions retain the previous plan and the reason for changing it.

[[resources/kickoff.md|The kickoff]] records ownership. Field feedback changed the architecture; see [[digest/wiki/local-first.md|the current local-first decision]]. This draft preserves history, not the current architecture.
