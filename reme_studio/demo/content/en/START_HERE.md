# Try ReMe Studio

This fictional **Aurora team knowledge assistant** workspace turns scattered meetings, decisions, and experience into traceable, reusable memory. Open, edit, save, and download Markdown directly in your browser.

## 1. Follow a memory to its source

Open [[digest/wiki/local-first.md|the local-first decision]]. Its sources are [[resources/offline-feedback.md|field feedback]] and [[daily/2026-09-15/decision.md|the decision diary]]. The earlier [[resources/requirements.md|requirements draft]] still describes a cloud-first plan, so you can compare the old proposal with the current conclusion.

## 2. Find a topic across directories

Choose **Search / Tags** above and select `local_first`. Resources, daily notes, knowledge, and procedures share this topic. Add the keyword “offline” to narrow the results. Tags come from each file's `memory_tags` front matter, rather than a separate hand-maintained category list.

## 3. Edit your browser copy

Open [[digest/personal/communication.md|communication preferences]] and switch to Edit. Replace the tag `communication` with `writing`, save, and check the tag counts and results. Download exports the file; Reset demo restores the starting workspace.

## 4. Explore links and answers

Choose Graph beside a Knowledge category. Select a node to inspect its incoming and outgoing links, then open the source note. Start a Chat, send a sample question, and expand `search` and `read` to inspect the actual example files.

> Graphs and keyword filters run in your browser. Chat answers are scripted; editing a document does not generate a new model answer. Changes stay in this browser and disappear if site data is cleared.

To use your own workspace, follow the documentation above, run `reme start`, and open your local Studio.
