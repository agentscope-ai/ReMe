# Communication preferences

Lin wants project updates to lead with a conclusion, followed by sources and next steps. Do not describe a plan as completed work; mark unknowns explicitly.

## Reusable rules

- Keep an update to three paragraphs where possible.
- Attach an original-file link to significant conclusions.
- Name an owner and deadline for each action.
- State the verified scope without expanding performance claims.
