# Aurora

Aurora is a five-person team's knowledge-assistant pilot. It helps members recover project context, retain reasons behind decisions, and reuse successful procedures.

## Current agreements

- Durable data lives in user-owned Markdown files; see [[digest/wiki/local-first.md|the local-first decision]].
- The first pilot excludes multi-device synchronization; see [[digest/wiki/sync.md|scope boundaries]].
- [[digest/wiki/memory-tags.md|Memory tags]] collect topics, while wikilinks express explicit file relationships.
