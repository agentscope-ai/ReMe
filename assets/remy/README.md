# Remy character assets

Remy is ReMe's original long-haired bookmark companion. The desktop reads the twelve animations from
[`anime/animations/v1/manifest.json`](anime/animations/v1/manifest.json) and the PNG frames it names.

The [animation source guide](anime/animations/v1/README.md) describes the source sheets, generation prompts,
frame timing and rebuild command. Use the desktop's **Right-click → Play animation** menu to preview the clips.
See [ReMe Desktop](../../reme_desktop/README.md) for launch instructions.

Only the manifest and runtime frames enter desktop packages. Original sheets and prompts remain in this repository
so the frames can be rebuilt. Duplicate archives, static-pose experiments and unused video exports are excluded.

The artwork was generated with the built-in imagegen tool from the user's selected original character.
DSH Pet informed interaction research; its artwork, prompts, animations and source code were not used.
